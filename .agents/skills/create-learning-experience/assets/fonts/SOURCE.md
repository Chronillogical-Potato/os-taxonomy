# Fredoka font source

Fredoka is the open-source rounded substitute used by this public skill, not
Marble’s proprietary Round font. Unmodified variable font, weights 300–700,
width axis retained. Source: https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/fredoka

`Fredoka-variable.ttf` is renamed from `Fredoka[wdth,wght].ttf` without modifying
the font. Its SIL Open Font License and original copyright are in `OFL.txt`.
Retain that notice when embedding or redistributing the font. This asset remains
under its own OFL terms rather than the repository's prose/content license.
